## 1. 为什么必须改（不是“为了表达而表达”）

`00-整体设计.md` §6.1 与 Harness §1 要求 `stop_reason` **11 值必备**；`agent_run` 的终态必须能区分 `BUDGET_EXHAUSTED` 与 `FAILED`。但实测：

- `openapi.v1.frozen.json` 中 `stop_reason` **0 次命中**；
- `agent_run`（v0018 双档）**无该列**；
- `py/` 线的 `AgentRun` 模型也没有（`_old/.../database/models/conversation.py:63`）。

⇒ 用 `status` / `error_type` / `token_usage` / `agent_event.payload` 替代都会**丢失语义或失去可查询性**（`GET /runs/{id}` 重载后无法回答“为什么停了”）。这是冻结面的**真实缺口**，不是测试口径问题。
